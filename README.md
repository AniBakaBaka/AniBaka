## 简介


**Baka** 是使用 Flutter 开发的支持多番剧源和弹幕的看番软件。

> **注意**：本项目目前为闭源发行。本仓库主要用于**发布版本**、**用户反馈**以及**Bug 追踪**。


---

## ✨ 特性 | Features
功能支持

分类| 支持内容| 简单说明
多源生态| 内置主流番剧源| 内置 Cycani、Gugu、Anime1、XiFanACG 等番剧源，开箱即用。
多源生态| 自定义源管理| 支持源的新建、编辑、启用、禁用、导入、导出与分享。
多源生态| 聚合搜索| 支持多个番剧源统一搜索，减少反复切换网站的操作。
多源生态| 源配置导入| 支持 "baka://" 链接和原始 JSON 格式导入源配置。
多源生态| 验证码自动处理| 部分源支持自动处理验证码。
播放器| mpv 播放内核| 基于 "media_kit" / "libmpv"，提供稳定的视频播放体验。
播放器| 多线路播放| 同一剧集支持多条播放线路，可自由切换。
播放器| 倍速播放| 支持常规倍速调节，也支持长按屏幕临时倍速。
播放器| 片头片尾跳过| 可设置片头片尾跳过时长，并支持撤销跳过。
播放器| 播放进度记忆| 自动记录每集播放进度。
播放器| 画面比例调整| 支持多种画面填充和显示比例切换。
播放器| 手势控制| 支持滑动调节亮度和音量。
画质增强| Anime4K 实时增强| 全端内置 Anime4K 算法，可对视频进行实时超分辨率增强。
弹幕| 弹幕显示控制| 支持字体大小、显示区域、滚动速度、透明度、描边宽度等调节。
弹幕| 弹幕过滤| 支持顶部、底部、滚动弹幕过滤，也支持关键词屏蔽和重复弹幕过滤。
字幕| 字幕管理| 支持字幕相关管理功能，提升多语言观看体验。
媒体控制| 系统媒体控制| 支持 Android 通知栏、iOS 锁屏、macOS 控制中心媒体控制。
投屏| DLNA 投屏| 支持将视频投屏到兼容 DLNA 的设备播放。
番剧资料| 番剧详情页| 支持查看 Infobox、声优信息和收藏状态分布。
番剧资料| 新番更新表| 支持按星期查看当季番剧更新时间。
番剧资料| 排行榜| 支持查看热门番剧排行，并可切换不同排行类型。
追番与历史| 追番收藏| 支持将番剧加入收藏，并按想看、在看、看过等状态分类管理。
追番与历史| 观看历史| 自动记录观看历史，可从历史记录中快速续播。
追番与历史| 多端同步| 支持本地历史与远端同步，实现多端进度衔接。
下载与离线| 视频缓存下载| 支持视频下载、断点续传和离线播放。
下载与离线| 弹幕离线保存| 下载完成后可自动保存弹幕文件，离线观看时也可加载弹幕。
媒体库| 本地媒体库| 支持浏览和管理本地已下载的视频资源。
媒体库| WebDAV 远程存储| 支持本地存储与 WebDAV 远程存储统一管理。
界面适配| 桌面端优化| 针对大屏设备进行界面适配。
界面适配| 平板优化| 支持平板设备的大屏 UI 布局变化。
界面适配| Android TV 适配| 支持 TV 自动检测、横屏沉浸模式和遥控器友好操作。
个性化| 主题切换| 支持深色模式、浅色模式和跟随系统。
个性化| 字体自定义| 支持字体切换、字体缩放和字重调节。

## 📥 下载与安装 | Download & Installation

### Windows
1. 前往 **[Releases](https://github.com/AniBakaBaka/AniBaka/releases)** 页面。
2. 下载最新的 `Baka_Setup.exe` (安装版) 或 `Baka_Windows_Portable.zip` (便携版)。
3. 安装或解压后直接运行 `Baka.exe`。

### Android
1. 前往 **[Releases](https://github.com/AniBakaBaka/AniBaka/releases)** 页面。
2. 下载最新的 `app-release.apk`。
3. 如果是首次安装，请允许浏览器或文件管理器安装未知来源应用。

### iOS / macOS
目前 iOS 版本暂未上架 App Store。
- **macOS**: 可载 `dmg` 镜像（如有发布）或等待后续签名版本。
- **iOS**: 仅自签安装。
